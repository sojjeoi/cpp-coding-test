# 등수 매기기 (Level 0)

## 문제
학생들의 두 과목 점수 [국어, 수학]이 담긴 2차원 배열 score가 주어질 때, 각 학생의 총점(두 점수의 합) 기준 등수를 매긴 배열을 return 하라. 총점이 같으면 같은 등수를 받는다.

## 접근
각 학생의 총점을 구해 배열 v에 담고, 복사본을 총점이 높은 게 1등이 되도록 **내림차순**으로 정렬한다.
원본 순서대로 각 학생의 총점을 정렬된 배열에서 `find`로 찾으면, 그 값이 처음 나타나는 위치(0-index)가 곧 "자신보다 총점이 높은 학생 수"와 같다. 여기에 1을 더하면 등수가 된다. 동점자는 같은 값이라 `find`가 항상 같은(가장 앞) 위치를 찾아주므로 자연스럽게 같은 등수를 받는다.

## 코드
```cpp
#include <algorithm>
using namespace std;

vector<int> solution(vector<vector<int>> score) {
    vector<int> total;
    for (vector<int> sc : score) {
        total.push_back(sc[0] + sc[1]);
    }
    vector<int> sorted_total = total;
    sort(sorted_total.begin(), sorted_total.end(), greater<int>());

    vector<int> answer;
    for (int x : total) {
        auto it = find(sorted_total.begin(), sorted_total.end(), x);
        answer.push_back((it - sorted_total.begin()) + 1);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 총점을 내림차순으로 정렬해 등수 기준 배열 생성 |
| `find` | 정렬된 배열에서 원래 총점의 위치(=등수-1)를 탐색 |
