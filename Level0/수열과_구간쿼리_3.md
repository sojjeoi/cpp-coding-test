# 수열과 구간 쿼리 3 (Level 0)

## 문제
정수 배열 arr와 쿼리 배열 queries가 주어질 때, 각 쿼리 [i, j]에 대해 arr[i]와 arr[j]를 순서대로 swap한 뒤, 모든 쿼리를 처리한 최종 배열을 return 하라.

## 접근
arr를 복사한 뒤 각 쿼리마다 `swap`으로 두 위치의 값을 맞바꾼다.

## 코드
```cpp
#include <algorithm>
vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    vector<int> answer = arr;
    for (vector<int> query : queries) {
        int a = query[0];
        int b = query[1];
        swap(answer[a], answer[b]);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `swap` | 쿼리로 지정된 두 인덱스의 값을 교환 |
