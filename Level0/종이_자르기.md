# 종이 자르기 (Level 0)

## 문제
세로 N, 가로 M 크기의 종이를 가위질로 잘라 모든 조각을 1x1 크기로 만들려고 한다. 가위질 한 번은 기존 조각 하나를 완전히 가로지르는 절단 한 번을 의미할 때, 필요한 최소 가위질 횟수를 return 하라.

## 접근
먼저 세로로 N-1번 잘라 종이를 N개의 가로 줄(각각 1 x M)로 나눈다. 그다음 각 줄을 M-1번씩 잘라 1x1 조각 M개로 만들어야 하므로 N줄 * (M-1)번이 추가로 필요하다.
총 가위질 횟수 = (N-1) + N*(M-1). 전개하면 NM - N - 1 + N = NM - 1이 되어, 사실 어떤 순서로 잘라도 가위질 한 번마다 조각 수가 정확히 1개씩 늘어나므로 (1개 → N*M개) 최소 횟수는 항상 N*M - 1이다.

## 코드
```cpp
int solution(int M, int N) {
    return M * N - 1;
}
```

## 사용 함수
– (가위질마다 조각 수가 1씩 늘어난다는 성질을 이용한 공식)
