# 삼각형의 완성조건 (1) (Level 0)

## 문제
세 변의 길이가 담긴 배열 sides가 주어질 때, 삼각형이 성립하는지 1/0으로 반환하라.

## 접근
정렬 후 가장 짧은 두 변의 합이 가장 긴 변보다 크면 성립.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> sides) {
    sort(sides.begin(), sides.end());
    return (sides[0] + sides[1] > sides[2]) ? 1 : 0;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 세 변을 정렬해 가장 긴 변을 마지막에 두기 |
