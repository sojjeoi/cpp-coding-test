# 약수 구하기 (Level 0)

## 문제
정수 n이 주어질 때, n의 약수를 오름차순으로 담은 배열을 반환하라.

## 접근
1부터 n까지 돌면서 n을 나눠서 나머지가 0인 수들을 순서대로 push_back하면, 자연스럽게 오름차순 배열이 만들어진다.

## 코드
```cpp
vector<int> solution(int n) {
    vector<int> answer;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) answer.push_back(i);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 for문만 사용, STL 없음 |
