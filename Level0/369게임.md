# 369게임 (Level 0)

## 문제
숫자 order가 주어질 때, 그 숫자에 3, 6, 9가 몇 번 등장하는지 반환하라.

## 접근
숫자를 문자열로 변환 후 count()로 '3','6','9' 개수를 합산.

## 코드
```cpp
#include <algorithm>
int solution(int order) {
    string s = to_string(order);
    int answer = 0;
    answer += count(s.begin(), s.end(), '3');
    answer += count(s.begin(), s.end(), '6');
    answer += count(s.begin(), s.end(), '9');
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 변환 |
| `count` | 특정 문자의 등장 횟수 세기 |
