# 모음 제거하기 (Level 0)

## 문제
문자열 my_string이 주어질 때 모음(a, e, i, o, u)을 모두 제거한 문자열을 반환하라.

## 접근
erase-remove idiom을 사용하되, 제거 대상이 여러 문자(모음 5개)이므로 단일 값 비교인 remove() 대신
조건 함수를 받는 remove_if()를 사용해 "모음 문자열 안에 포함되는지"를 조건으로 판별한다.

## 코드
```cpp
#include <algorithm>
string solution(string my_string) {
    string vowels = "aeiou";
    my_string.erase(
        remove_if(my_string.begin(), my_string.end(),
            [&](char c) { return vowels.find(c) != string::npos; }),
        my_string.end());
    return my_string;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `remove_if` | 조건(모음 포함 여부)을 만족하는 문자를 뒤로 몰아내고 유효 구간 끝 반환 |
| `erase` | remove_if가 반환한 지점부터 끝까지 실제로 삭제 |
