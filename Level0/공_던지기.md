# 공 던지기 (Level 0)

## 문제
n명이 원형으로 서서 2명씩 건너뛰며 공을 패스할 때, k번째로 공을 받는 사람의 번호를 반환하라.

## 접근
규칙을 찾으면 인덱스 = (k-1)*2 % n.

## 코드
```cpp
int solution(vector<int> numbers, int k) {
    int n = numbers.size();
    return numbers[(k - 1) * 2 % n];
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 수식으로 규칙 계산, STL 없음 |
