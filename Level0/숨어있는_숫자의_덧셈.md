# 숨어있는 숫자의 덧셈 (1) (Level 0)

## 문제
문자열 my_string 안에 있는 숫자를 전부 찾아 더한 값을 반환하라.

## 접근
isdigit()으로 숫자 문자만 골라 '0'을 빼서 실제 숫자로 변환 후 합산.

## 코드
```cpp
#include <cctype>
int solution(string my_string) {
    int answer = 0;
    for (char c : my_string) if (isdigit(c)) answer += (c - '0');
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `isdigit` | 문자가 숫자인지 판별 |
