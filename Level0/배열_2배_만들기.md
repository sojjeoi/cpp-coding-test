# 배열 2배 만들기 (Level 0)

## 문제
정수 배열 numbers의 각 원소에 2를 곱한 배열을 반환하라.

## 접근
배열을 순회하며 각 원소 * 2를 새 배열에 push_back.

## 코드
```cpp
vector<int> solution(vector<int> numbers) {
    vector<int> answer;
    for (int x : numbers) answer.push_back(2 * x);
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 for문만 사용, STL 없음 |
