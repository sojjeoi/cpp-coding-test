# 문자열 겹쳐쓰기 (Level 0)

## 문제
문자열 my_string, overwrite_string과 정수 s가 주어질 때, my_string의 s번째 위치부터 overwrite_string 길이만큼을 overwrite_string으로 덮어쓴 문자열을 반환하라.

## 접근
`string::replace(시작위치, 바꿀길이, 새문자열)`을 쓰면 지정한 구간을 통째로 다른 문자열로 교체해준다.
바꿀 길이를 overwrite_string의 길이로 주면 정확히 그 부분만 덮어써진다.

## 코드
```cpp
string solution(string my_string, string overwrite_string, int s) {
    my_string.replace(s, overwrite_string.size(), overwrite_string);
    return my_string;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::replace` | 지정한 구간을 새 문자열로 덮어쓰기 |
