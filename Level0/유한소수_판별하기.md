# 유한소수 판별하기 (Level 0)

## 문제
분자 a, 분모 b가 주어질 때, a/b를 기약분수로 나타냈을 때 유한소수이면 1, 무한소수이면 2를 return 하라. (분모를 2와 5로만 소인수분해할 수 있으면 유한소수)

## 접근
먼저 `gcd`로 약분해 기약분수로 만든다. 그 뒤 분모를 2로 나눠떨어지는 만큼 계속 나누고, 5로도 나눠떨어지는 만큼 계속 나눈다. 남은 분모가 1이면 2와 5 이외의 소인수가 없었다는 뜻이므로 유한소수(1), 아니면 무한소수(2)다.

## 코드
```cpp
#include <numeric>
int solution(int a, int b) {
    int g = gcd(a, b);
    b /= g;
    while (b % 2 == 0) b /= 2;
    while (b % 5 == 0) b /= 5;
    return (b == 1) ? 1 : 2;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `gcd` | 기약분수로 약분 |

## 오답 노트
분모를 소인수분해해서 나온 소인수 목록에 2, 5가 아닌 값이 있는지 검사하는 방식도 가능하지만, `if(x != 2 || x != 5)`처럼 쓰면 안 된다. 어떤 x도 2와 5를 동시에 만족할 수 없으니 이 조건은 항상 참이 되어버린다. "2도 아니고 5도 아니면"은 `&&`로 써야 한다: `if(x != 2 && x != 5)`.
