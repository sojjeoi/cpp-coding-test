# 로그인 성공? (Level 0)

## 문제
로그인 시도한 아이디·비밀번호 id_pw와, 등록된 유저들의 [아이디, 비밀번호] 목록 db가 주어질 때 로그인 결과를 return 하라.
- 일치하는 아이디가 없으면 "fail"
- 아이디는 있고 비밀번호가 틀리면 "wrong pw"
- 아이디·비밀번호가 모두 맞으면 "login"

## 접근
기본값을 "fail"로 두고 db를 순회하며 아이디가 일치하는 유저를 찾으면, 그 자리에서 비밀번호까지 비교해 결과를 정하고 더 볼 필요 없으니 break한다.

## 코드
```cpp
string solution(vector<string> id_pw, vector<vector<string>> db) {
    string answer = "fail";
    for (vector<string> info : db) {
        if (id_pw[0] == info[0]) {
            answer = (id_pw[1] == info[1]) ? "login" : "wrong pw";
            break;
        }
    }
    return answer;
}
```

## 사용 함수
– (반복문과 조건문만으로 처리)
