# 이진수 더하기 (Level 0)

## 문제
이진수를 나타내는 두 문자열 bin1, bin2가 주어질 때, 두 이진수를 더한 값을 이진수 문자열로 return 하라.

## 접근
`stoi(bin, nullptr, 2)`로 이진수 문자열을 10진수 정수로 해석해 더한다. 합을 다시 이진수로 바꿀 때는 2로 나눈 나머지를 계속 이어 붙이는데, 이렇게 하면 자리가 거꾸로(낮은 자리부터) 쌓이므로 마지막에 `reverse`로 뒤집어야 한다.

## 코드
```cpp
#include <string>
#include <algorithm>
using namespace std;

string solution(string bin1, string bin2) {
    int sum = stoi(bin1, nullptr, 2) + stoi(bin2, nullptr, 2);
    if (sum == 0) return "0";
    string answer = "";
    while (sum > 0) {
        answer += to_string(sum % 2);
        sum /= 2;
    }
    reverse(answer.begin(), answer.end());
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `stoi` | 이진수 문자열을 10진수 정수로 변환(세 번째 인자로 진법 지정) |
| `reverse` | 거꾸로 쌓인 이진수 자릿수를 올바른 순서로 뒤집기 |
