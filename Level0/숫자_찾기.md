# 숫자 찾기 (Level 0)

## 문제
정수 num과 한 자리 숫자 k가 주어질 때, num을 문자열로 봤을 때 k가 처음 등장하는 위치(1-indexed)를 반환하라. 없으면 -1을 반환하라.

## 접근
num을 to_string으로 문자열로 바꾸고, k를 문자로 바꾼 뒤(`k + '0'`) find로 찾는다.
find는 여러 번 등장해도 가장 먼저 찾은 위치를 반환하므로 문제 조건과 정확히 맞는다. 찾은 인덱스는 0-indexed이므로 +1 해준다.

## 코드
```cpp
int solution(int num, int k) {
    string s = to_string(num);
    int answer;
    if (s.find(k + '0') != string::npos) {
        answer = s.find(k + '0') + 1;
    } else {
        answer = -1;
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 변환 |
| `string::find` | k에 해당하는 숫자 문자가 처음 등장하는 위치 탐색 |
