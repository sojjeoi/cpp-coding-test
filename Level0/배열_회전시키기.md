# 배열 회전시키기 (Level 0)

## 문제
정수 배열 numbers와 방향 문자열 direction("left" 또는 "right")이 주어질 때, 배열을 해당 방향으로 한 칸 회전시킨 결과를 반환하라.

## 접근
rotate(first, middle, last)는 middle 위치의 원소가 맨 앞에 오도록 구간을 회전시킨다.
- 오른쪽 회전: 마지막 원소가 맨 앞으로 와야 하므로 rotate(begin(), end()-1, end())
- 왼쪽 회전: 두 번째 원소가 맨 앞으로 와야 하므로 rotate(begin(), begin()+1, end())

## 코드
```cpp
#include <algorithm>
vector<int> solution(vector<int> numbers, string direction) {
    vector<int> answer = numbers;
    if (direction == "right") {
        rotate(answer.begin(), answer.end() - 1, answer.end());
    } else {
        rotate(answer.begin(), answer.begin() + 1, answer.end());
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `rotate` | 지정한 middle 위치의 원소가 맨 앞에 오도록 구간을 회전 |
