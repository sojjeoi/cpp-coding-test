# 가장 큰 수 찾기 (Level 0)

## 문제
정수 배열 array가 주어질 때, 배열에서 가장 큰 값과 그 값의 인덱스를 [최댓값, 인덱스] 형태로 반환하라.

## 접근
for문을 돌면서 지금까지 본 값 중 더 큰 값이 나올 때마다 최댓값과 그 인덱스를 함께 갱신한다.

## 코드
```cpp
vector<int> solution(vector<int> array) {
    int max_val = array[0];
    int max_idx = 0;
    for (int i = 0; i < array.size(); i++) {
        if (array[i] > max_val) {
            max_val = array[i];
            max_idx = i;
        }
    }
    return {max_val, max_idx};
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 for문만 사용, STL 없음 |
