# 수열과 구간 쿼리 2 (Level 0)

## 문제
정수 배열 arr와 쿼리 배열 queries가 주어질 때, 각 쿼리 [s, e, k]에 대해 s≤i≤e 범위에서 k보다 크면서 가장 작은 arr[i]를 찾아 배열로 return 하라. 그런 값이 없으면 -1을 넣는다.

## 접근
각 쿼리마다 [s, e] 구간을 순회하며 k보다 큰 값 중 지금까지 찾은 결과보다 작은 값이 나오면 갱신한다.

## 코드
```cpp
vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    vector<int> answer;
    for (vector<int> query : queries) {
        int s = query[0], e = query[1], k = query[2];
        int result = -1;
        for (int i = s; i <= e; i++) {
            if (arr[i] > k && (result == -1 || arr[i] < result)) {
                result = arr[i];
            }
        }
        answer.push_back(result);
    }
    return answer;
}
```
