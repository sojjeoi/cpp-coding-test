# 중복된 문자 제거 (Level 0)

## 문제
문자열 my_string에서 중복된 문자를 제거하고 처음 등장한 순서를 유지한 문자열을 반환하라.

## 접근
결과 문자열에 이미 있는 문자인지 find로 확인 후 없으면 추가.

## 코드
```cpp
string solution(string my_string) {
    string answer = "";
    for (char c : my_string) if (answer.find(c) == string::npos) answer += c;
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::find` | 결과 문자열에 해당 문자가 이미 있는지 확인 |
