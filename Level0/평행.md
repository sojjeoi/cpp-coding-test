# 평행 (Level 0)

## 문제
네 점의 좌표가 담긴 2차원 배열 dots가 주어질 때, 이 중 두 점씩 짝지어 선분을 두 개 만들었을 때 평행이 되는 경우가 있으면 1, 없으면 0을 return 하라.

## 접근
4개의 점을 두 쌍으로 나누는 방법은 (0,1)-(2,3), (0,2)-(1,3), (0,3)-(1,2) 총 3가지뿐이다. 각 경우에 두 선분이 평행인지 확인한다.

기울기 비교는 나눗셈(`(y2-y1)/(x2-x1)`)으로 하면 0으로 나누는 경우(수직선)를 따로 처리해야 해서 불안정하다. `a/b == c/d`는 `a*d == b*c`와 동치이므로, 곱셈으로 바꿔서 비교한다: `(y2-y1)*(x4-x3) == (x2-x1)*(y4-y3)`.

## 코드
```cpp
bool isParallel(vector<vector<int>>& dots, int p1, int p2, int p3, int p4) {
    int dy1 = dots[p2][1] - dots[p1][1];
    int dx1 = dots[p2][0] - dots[p1][0];
    int dy2 = dots[p4][1] - dots[p3][1];
    int dx2 = dots[p4][0] - dots[p3][0];
    return dy1 * dx2 == dx1 * dy2;
}

int solution(vector<vector<int>> dots) {
    if (isParallel(dots, 0, 1, 2, 3)) return 1;
    if (isParallel(dots, 0, 2, 1, 3)) return 1;
    if (isParallel(dots, 0, 3, 1, 2)) return 1;
    return 0;
}
```

## 사용 함수
– (나눗셈 대신 곱셈으로 기울기 비교)
