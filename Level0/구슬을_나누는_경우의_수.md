# 구슬을 나누는 경우의 수 (Level 0)

## 문제
balls개의 구슬 중에서 share개를 순서 상관없이 고르는 경우의 수를 반환하라.

## 접근
조합 공식 balls! / (share! * (balls-share)!)을 그대로 계산하면 팩토리얼 오버플로우/타임 오류가 발생한다.
대신 (balls-i+1)을 곱하고 i로 나누는 것을 share번 반복하는 방식으로 매 단계마다 값을 줄여가며 계산한다.
결과 값의 범위가 커서 answer 타입은 long long을 사용해야 한다.

## 코드
```cpp
long long solution(int balls, int share) {
    long long answer = 1;
    for (int i = 1; i <= share; i++) {
        answer *= (balls - i + 1);
        answer /= i;
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 조합(nCr) 계산 시 곱셈/나눗셈을 매 단계 수행해 오버플로우 방지, `long long` 타입 필요 |
