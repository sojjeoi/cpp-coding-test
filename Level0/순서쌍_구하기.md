# 순서쌍 구하기 (Level 0)

## 문제
정수 n이 주어질 때, 두 정수 (a, b)의 곱이 n이 되는 순서쌍의 개수를 반환하라.

## 접근
n의 약수의 개수 = 순서쌍의 개수. 1부터 n까지 나눠서 나머지가 0인 경우를 센다.

## 코드
```cpp
int solution(int n) {
    int answer = 0;
    for (int i = 1; i <= n; i++) if (n % i == 0) answer++;
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 for문만 사용, STL 없음 |
