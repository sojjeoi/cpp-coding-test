# 등차수열의 특정 항만 더하기 (Level 0)

## 문제
첫째항 a, 공차 d인 등차수열에서, 몇 번째 항을 더할지 나타내는 불리언 배열 included가 주어질 때, included[i]가 true인 (i+1)번째 항들의 합을 return 하라.
예) a=3, d=4 → 3, 7, 11, 15, 19, ...

## 접근
i번째(0-index) 항은 `a + d*i`이다. included를 순회하며 true인 인덱스의 항만 더한다.

## 코드
```cpp
int solution(int a, int d, vector<bool> included) {
    int answer = 0;
    for (int i = 0; i < included.size(); i++) {
        if (included[i]) answer += a + d * i;
    }
    return answer;
}
```

## 사용 함수
– (등차수열 공식과 반복문만으로 처리)
