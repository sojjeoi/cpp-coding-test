# 대소문자 바꾸기 (Level 0)

## 문제
문자열 my_string이 주어질 때, 대문자는 소문자로, 소문자는 대문자로 바꾼 문자열을 반환하라.

## 접근
`for (char &c : answer)`처럼 참조(&)로 순회하면 복사본이 아니라 원본 문자 자체를 가리키므로,
반복문 안에서 c를 바꾸면 answer 문자열이 그대로 바뀐다. islower/isupper로 대소문자를 판별해 toupper/tolower로 변환한다.

## 코드
```cpp
#include <cctype>
string solution(string my_string) {
    string answer = my_string;
    for (char &c : answer) {
        if (islower(c)) c = toupper(c);
        else if (isupper(c)) c = tolower(c);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `islower` / `isupper` | 문자가 소문자/대문자인지 판별 |
| `toupper` / `tolower` | 대문자/소문자로 변환 |
