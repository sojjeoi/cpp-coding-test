# 최빈값 구하기 (Level 0)

## 문제
정수 배열 array가 주어질 때 최빈값을 반환하라. 최빈값이 여러 개면 -1을 반환하라.

## 접근
값별 등장 횟수를 카운트 배열에 저장, 최대 횟수와 그 위치를 찾고, 최대 횟수를 가진 값이 여러 개면 -1.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> array) {
    int cnt[1001] = {0};
    for (int x : array) cnt[x]++;
    int maxcnt = *max_element(cnt, cnt + 1001);
    int answer = max_element(cnt, cnt + 1001) - cnt;
    if (count(cnt, cnt + 1001, maxcnt) > 1) answer = -1;
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `max_element` | 배열에서 최댓값(포인터/이터레이터) 찾기 |
| `count` | 최댓값이 몇 번 등장하는지(동률 확인) |
