# 문자열 곱하기 (Level 0)

## 문제
문자열 my_string과 정수 k가 주어질 때, my_string을 k번 반복해서 이어붙인 문자열을 반환하라.

## 접근
`string(횟수, 문자)` 생성자는 두 번째 인자로 char 하나만 받을 수 있어서, 문자열 전체를 반복하는 이 문제에는 쓸 수 없다.
대신 k번 반복문을 돌며 my_string을 answer에 이어붙인다(`+=`).

## 코드
```cpp
string solution(string my_string, int k) {
    string answer = "";
    for (int i = 1; i <= k; i++) {
        answer += my_string;
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | `string(n, ch)`는 문자 하나만 반복 가능해 이 문제엔 부적합, 대신 `+=` 반복으로 해결 |
