# 안전지대 (Level 0)

## 문제
n x n 크기의 게임판 board에 지뢰(1)가 표시되어 있을 때, 지뢰와 지뢰 주변 8칸(위험지역)을 제외한 안전지대의 칸 수를 return 하라.

## 접근
[겹치는 선분의 길이](겹치는_선분의_길이.md)와 같은 방식으로, 위험한 칸에 ++로 표시를 누적한 뒤 0인 칸의 개수를 센다.
지뢰 좌표 (i, j)를 기준으로 위험지역은 (i-1,j-1)~(i+1,j+1)의 3x3, 총 9칸이다. 배열 경계(-1, n)에서 음수 인덱스가 나오는 걸 피하기 위해, 실제 크기보다 위아래·좌우로 한 칸씩 넓은 (n+2)x(n+2) 배열을 만들고, 실제 좌표 (i, j)를 배열의 (i+1, j+1)에 대응시킨다(오프셋 +1). 그러면 3x3 범위는 항상 배열의 (i, i+1, i+2) x (j, j+1, j+2)로 안전하게 들어간다.
마지막에 board 범위(실제 좌표 0~n-1 → 배열 인덱스 1~n)만 보고 0인 칸을 센다.

## 코드
```cpp
int solution(vector<vector<int>> board) {
    int answer = 0;
    int n = board.size();
    vector<vector<int>> v(n + 2, vector<int>(n + 2, 0));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 1) {
                for (int di = 0; di <= 2; di++) {
                    for (int dj = 0; dj <= 2; dj++) {
                        v[i + di][j + dj]++;
                    }
                }
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (v[i][j] == 0) answer++;
        }
    }
    return answer;
}
```

## 사용 함수
– (오프셋을 준 2차원 카운팅 배열로 처리)
