# 특정 문자 제거하기 (Level 0)

## 문제
문자열 my_string에서 문자 letter를 모두 제거한 문자열을 반환하라.

## 접근
erase-remove idiom으로 해당 문자를 전부 제거.

## 코드
```cpp
#include <algorithm>
string solution(string my_string, string letter) {
    my_string.erase(remove(my_string.begin(), my_string.end(), letter[0]), my_string.end());
    return my_string;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `remove` | 조건에 맞는 문자를 뒤로 몰아내고 유효 구간 끝 반환 |
| `erase` | remove가 반환한 지점부터 끝까지 실제로 삭제 |
