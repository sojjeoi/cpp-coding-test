# 제곱수 판별하기 (Level 0)

## 문제
정수 n이 매개변수로 주어질 때, n이 어떤 정수 x의 제곱수라면 1을, 아니라면 2를 return 하라.

## 접근
1부터 1000까지 i를 늘려가며 i*i가 n과 같은지 확인한다. n의 범위가 1,000,000 이하이므로 i는 1000까지만 확인하면 충분하다. 찾으면 더 볼 필요 없으니 break.

## 코드
```cpp
int solution(int n) {
    int answer = 2;
    for (int i = 1; i <= 1000; i++) {
        if (i * i == n) {
            answer = 1;
            break;
        }
    }
    return answer;
}
```
