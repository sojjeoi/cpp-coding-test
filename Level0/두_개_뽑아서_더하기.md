# 두 개 뽑아서 더하기 (Level 0)

## 문제
정수 배열 numbers가 주어질 때, 서로 다른 인덱스에 있는 두 수를 뽑아 더해서 만들 수 있는 모든 합을 중복 없이 오름차순으로 정렬한 배열을 return 하라.

## 접근
가능한 모든 쌍(i<j)의 합을 구해 담은 뒤, `sort`로 정렬하고 `unique`+`erase`로 중복을 제거한다. `unique`는 정렬된 상태에서만 인접한 중복을 제대로 걸러내므로 반드시 정렬 후에 적용해야 한다.

## 코드
```cpp
#include <algorithm>
using namespace std;

vector<int> solution(vector<int> numbers) {
    vector<int> num;
    int n = numbers.size();
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            num.push_back(numbers[i] + numbers[j]);
        }
    }
    sort(num.begin(), num.end());
    num.erase(unique(num.begin(), num.end()), num.end());
    return num;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 합들을 오름차순 정렬 |
| `unique` + `erase` | 정렬된 배열에서 중복된 합 제거 |
