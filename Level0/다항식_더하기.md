# 다항식 더하기 (Level 0)

## 문제
x에 대한 항과 상수항이 공백으로 구분된 다항식 문자열 polynomial(예: "3x + 7 + x")이 주어질 때, 동류항을 정리한 식을 문자열로 return 하라.

## 접근
`stringstream`으로 공백 단위 토큰을 하나씩 읽는다.
- "+"는 건너뛴다.
- "x"면 계수 a에 1을 더한다.
- 마지막 글자가 'x'면(예: "3x") `stoi`로 숫자 부분만 읽어 a에 더한다. (`stoi`는 문자열 앞부분에서 숫자로 읽을 수 있는 만큼만 읽고 멈춘다)
- 그 외(순수 숫자)는 상수항 b에 더한다.

다 읽은 뒤 a가 0이면 상수항만 return, a가 1이면 "x"만, 아니면 "{a}x"를 만들고, b가 0이 아니면 "+{b}"를 붙인다.

## 코드
```cpp
#include <sstream>
#include <string>
using namespace std;

string solution(string polynomial) {
    int a = 0, b = 0;
    stringstream ss(polynomial);
    string s;
    while (ss >> s) {
        if (s == "+") continue;
        if (s == "x") a++;
        else if (s.back() == 'x') a += stoi(s);
        else b += stoi(s);
    }
    if (a == 0) return to_string(b);
    string answer = (a == 1) ? "x" : to_string(a) + "x";
    if (b != 0) answer += "+" + to_string(b);
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `stringstream` | 공백 기준으로 토큰 하나씩 읽기 |
| `stoi` | 문자열 앞부분의 숫자만 정수로 변환 |
| `string::back` | 토큰의 마지막 글자가 'x'인지 확인 |
