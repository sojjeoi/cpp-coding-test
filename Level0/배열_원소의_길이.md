# 배열 원소의 길이 (Level 0)

## 문제
문자열 배열 strlist가 주어질 때, 각 문자열의 길이를 담은 정수 배열을 반환하라.

## 접근
배열을 순회하며 각 문자열의 length()를 결과 배열에 넣기만 하면 된다.

## 코드
```cpp
vector<int> solution(vector<string> strlist) {
    vector<int> answer;
    for (string& s : strlist) answer.push_back(s.length());
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::length` | 문자열의 길이를 반환 |
