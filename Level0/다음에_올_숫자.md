# 다음에 올 숫자 (Level 0)

## 문제
등차수열 또는 등비수열을 이루는 정수 배열 common이 주어질 때, 마지막 항 다음에 올 숫자를 return 하라.

## 접근
먼저 첫 두 항의 차 d로 등차수열인지 검사한다(모든 연속한 두 항의 차가 d와 같은지 확인). 등차수열이면 마지막 항 + d를 반환한다. 등차수열이 아니면 등비수열이라고 보고, 첫 두 항의 비 r을 구해 마지막 항 * r을 반환한다.

## 코드
```cpp
int solution(vector<int> common) {
    int n = common.size();
    int d = common[1] - common[0];
    bool isArithmetic = true;
    for (int i = 1; i < n; i++) {
        if (common[i] - common[i - 1] != d) { isArithmetic = false; break; }
    }
    if (isArithmetic) return common[n - 1] + d;
    int r = common[1] / common[0];
    return common[n - 1] * r;
}
```

## 사용 함수
– (등차/등비 여부를 직접 검사하는 반복문으로 처리)
