# 주사위 게임 2 (Level 0)

## 문제
세 개의 주사위를 굴려 나온 눈 a, b, c가 매개변수로 주어질 때 다음 규칙으로 점수를 계산해 return 하라.
- 셋 다 같으면: (a+b+c) * (a²+b²+c²) * (a³+b³+c³)
- 둘만 같으면: (a+b+c) * (a²+b²+c²)
- 모두 다르면: a+b+c

## 접근
`pow(a, b)`로 a의 b승을 구한다. 세 값이 같은 개수에 따라 분기한다.

## 코드
```cpp
#include <cmath>
long long solution(int a, int b, int c) {
    long long sum = a + b + c;
    long long sumSq = pow(a, 2) + pow(b, 2) + pow(c, 2);
    long long sumCube = pow(a, 3) + pow(b, 3) + pow(c, 3);
    if (a == b && b == c) return sum * sumSq * sumCube;
    if (a == b || b == c || a == c) return sum * sumSq;
    return sum;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `pow` | 눈의 제곱, 세제곱 값을 계산 |
