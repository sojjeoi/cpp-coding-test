# 문자열 정렬하기 (Level 0)

## 문제
문자열 my_string이 주어질 때, my_string 안에 있는 숫자만 골라 오름차순으로 정렬한 문자열을 반환하라.

## 접근
"0123456789" 문자열을 기준으로 my_string의 각 문자가 숫자(0~9 중 하나)인지 find로 확인해 골라내고,
모아진 숫자 문자열을 sort로 오름차순 정렬한다.

## 코드
```cpp
#include <algorithm>
string solution(string my_string) {
    string digits = "0123456789";
    string answer;
    for (char c : my_string) {
        if (digits.find(c) != string::npos) answer += c;
    }
    sort(answer.begin(), answer.end());
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::find` | 문자가 숫자 문자열에 포함되는지(=숫자인지) 확인 |
| `sort` | 골라낸 숫자 문자들을 오름차순 정렬 |
