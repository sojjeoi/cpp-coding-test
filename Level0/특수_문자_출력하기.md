# 특수 문자 출력하기 (Level 0)

## 문제
`\`(백슬래시)나 `"`(큰따옴표)처럼 C++ 문자열 리터럴 안에서 특별한 의미를 가진 문자를 화면에 그대로 출력하라. (반환값 없음, 표준입출력)

## 접근
`\`나 `"`를 문자열 리터럴 안에 그대로 쓰면 컴파일러가 이스케이프 시퀀스로 해석해버린다. 실제 문자 그대로 출력하려면 앞에 백슬래시를 하나 더 붙여야 한다.
- `\` 출력 → `"\\"`
- `"` 출력 → `"\""`

## 코드
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "\\" << "\n";   // \ 출력
    cout << "\"" << "\n";   // " 출력
    return 0;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 이스케이프 시퀀스(`\\`, `\"`)만으로 해결 |
