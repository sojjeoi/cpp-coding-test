# 소인수분해 (Level 0)

## 문제
정수 n이 주어질 때 n의 소인수를 오름차순으로 반환하라.

## 접근
2부터 차례로 나누어 떨어지면 계속 나누고 인수를 기록, 나머지는 다음 수로 넘어간다. 중복은 unique로 제거.

## 코드
```cpp
#include <algorithm>
vector<int> solution(int n) {
    vector<int> answer;
    int i = 2;
    while (i <= n) {
        if (n % i == 0) { n /= i; answer.push_back(i); }
        else i++;
    }
    answer.erase(unique(answer.begin(), answer.end()), answer.end());
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `unique` | 인접한 중복 원소를 뒤로 몰아내고 유효 구간 끝 반환 |
| `erase` | unique가 반환한 지점부터 끝까지 실제로 삭제 |
