# 문자열 안에 문자열 (Level 0)

## 문제
문자열 str1과 str2가 주어질 때, str1 안에 str2가 연속된 부분 문자열로 포함되어 있으면 1, 포함되어 있지 않으면 2를 return 하라.

## 접근
str1을 처음부터 끝까지 훑으면서, 각 위치 i에서 str2 길이만큼 잘라낸 부분 문자열 `str1.substr(i, str2.size())`이 str2와 같은지 비교한다. 일치하는 위치를 찾으면 더 볼 필요가 없으니 바로 break로 종료한다.

## 코드
```cpp
#include <string>
using namespace std;

int solution(string str1, string str2) {
    int answer = 2;
    for (int i = 0; i < str1.size(); i++) {
        string temp = str1.substr(i, str2.size());
        if (temp == str2) {
            answer = 1;
            break;
        }
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::substr` | (시작위치, 길이)만큼 부분 문자열을 잘라내 str2와 비교 |
