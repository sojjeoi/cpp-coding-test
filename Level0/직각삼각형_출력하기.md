# 직각삼각형 출력하기 (Level 0)

## 문제
정수 n을 입력받아, 1줄에 별 1개부터 n개까지 늘려가며 출력하라. (반환값 없음, 표준입출력)

## 접근
1부터 n까지 반복하며 string(i, '*')로 별을 i개 만들어 출력.

## 코드
```cpp
int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cout << string(i, '*') << "\n";
    return 0;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string(n, ch)` | 문자 ch를 n번 반복한 문자열 생성 |
