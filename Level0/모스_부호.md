# 모스 부호 (1) (Level 0)

## 문제
공백으로 구분된 모스 부호 문자열 letter를 알파벳 문자열로 변환해 반환하라.

## 접근
모스-알파벳 매핑 테이블을 만들고, stringstream으로 공백 단위로 분리해 순서대로 변환.

## 코드
```cpp
#include <sstream>
#include <map>
string solution(string letter) {
    map<string, char> morse = {
        {".-",'a'},{"-...",'b'},{"-.-.",'c'},{"-..",'d'},{".",'e'},
        {"..-.",'f'},{"--.",'g'},{"....",'h'},{"..",'i'},{".---",'j'},
        {"-.-",'k'},{".-..",'l'},{"--",'m'},{"-.",'n'},{"---",'o'},
        {".--.",'p'},{"--.-",'q'},{".-.",'r'},{"...",'s'},{"-",'t'},
        {"..-",'u'},{"...-",'v'},{".--",'w'},{"-..-",'x'},{"-.--",'y'},{"--..",'z'}
    };
    string answer = "", x;
    stringstream ss(letter);
    while (ss >> x) answer += morse[x];
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `stringstream` | 공백 기준으로 문자열을 토큰 단위로 분리해 읽기 |
| `map` | 모스 부호 → 알파벳 매핑 테이블 |
