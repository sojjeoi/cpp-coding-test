# 최댓값 만들기 (1) (Level 0)

## 문제
정수 배열 numbers에서 두 수를 뽑아 곱했을 때 나올 수 있는 최댓값을 반환하라. (배열에는 음수도 포함될 수 있다)

## 접근
음수 두 개를 곱하면 양수가 되어 더 큰 값이 나올 수 있으므로, 가장 큰 두 값의 곱만으로는 부족하다. 정렬한 뒤 **가장 큰 두 값의 곱**과 **가장 작은 두 값의 곱**을 둘 다 구해 더 큰 쪽을 반환한다.
예) [1,2,-3,4,-5] → 정렬 [-5,-3,1,2,4] → 가장 작은 두 값의 곱 (-5)*(-3)=15, 가장 큰 두 값의 곱 4*2=8 → 15가 최댓값.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> numbers) {
    sort(numbers.begin(), numbers.end());
    int n = numbers.size();
    int a = numbers[0] * numbers[1];
    int b = numbers[n-1] * numbers[n-2];
    return max(a, b);
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 오름차순 정렬 후 양 끝 두 값씩 비교 |
| `max` | 최소값 두 개의 곱과 최댓값 두 개의 곱 중 더 큰 값 선택 |
