# 최댓값 만들기 (1) (Level 0)

## 문제
정수 배열 numbers에서 두 수를 뽑아 곱했을 때 나올 수 있는 최댓값을 반환하라.

## 접근
정렬 후 가장 큰 두 값(뒤에서 2개)을 곱한다.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> numbers) {
    sort(numbers.begin(), numbers.end());
    int n = numbers.size();
    return numbers[n-1] * numbers[n-2];
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 오름차순 정렬 후 뒤에서 2개 곱하기 |
