# 자릿수 더하기 (Level 0)

## 문제
정수 n이 주어질 때, n의 각 자릿수를 모두 더한 값을 반환하라.

## 접근
n을 문자열로 바꿔서 각 문자를 순회하며 `문자 - '0'`으로 실제 숫자 값으로 변환해 더한다.

## 코드
```cpp
int solution(int n) {
    string s = to_string(n);
    int answer = 0;
    for (char c : s) answer += (c - '0');
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 변환해 자릿수 단위로 순회 |
