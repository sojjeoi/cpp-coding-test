# 컨트롤 제트 (Level 0)

## 문제
공백으로 구분된 숫자와 "Z"가 섞인 문자열 s가 주어진다. "Z"가 나오면 바로 직전에 더했던 숫자를 취소(빼기)하고,
그 외에는 숫자를 더한다. 모든 처리가 끝난 뒤 남은 숫자들의 합을 반환하라.

## 접근
문자열이 공백으로 숫자가 구분되어 있으므로 stringstream으로 토큰 단위로 분리해 읽는다.
직전에 더한 값을 prev에 기억해두었다가, "Z"를 만나면 answer에서 prev를 빼고, 숫자를 만나면 stoi로 변환해 더한다.

## 코드
```cpp
#include <sstream>
int solution(string s) {
    stringstream ss(s);
    string temp;
    int answer = 0, prev = 0;
    while (ss >> temp) {
        if (temp == "Z") {
            answer -= prev;
        } else {
            prev = stoi(temp);
            answer += prev;
        }
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `stringstream` | 공백 기준으로 문자열을 토큰 단위로 분리해 읽기 |
| `stoi` | 문자열 토큰을 정수로 변환 |
