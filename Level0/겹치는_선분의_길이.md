# 겹치는 선분의 길이 (Level 0)

## 문제
수직선 위의 선분 정보가 2차원 배열 lines로 주어질 때(각 원소는 [시작점, 끝점]), 두 개 이상의 선분이 겹치는 구간의 총 길이를 return 하라.

## 접근
좌표가 음수일 수 있으므로 배열 인덱스로 쓰기 위해 100을 더해 offset을 준다. 각 선분이 지나가는 모든 단위 구간의 카운트를 ++로 누적한 뒤, 마지막에 카운트가 2 이상인 구간의 개수를 센다.

## 코드
```cpp
int solution(vector<vector<int>> lines) {
    int answer = 0;
    vector<int> arr(201, 0); // 좌표 범위(-100~100)를 커버하는 카운트 배열, 0으로 초기화
    for (vector<int> line : lines) {
        for (int i = line[0]; i < line[1]; i++) {
            arr[i + 100]++;
        }
    }
    for (int x : arr) {
        if (x >= 2) answer++;
    }
    return answer;
}
```

## 사용 함수
– (오프셋 배열에 카운팅하는 방식으로 처리)
