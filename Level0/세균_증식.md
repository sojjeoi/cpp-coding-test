# 세균 증식 (Level 0)

## 문제
박테리아는 1시간마다 두 배로 증식한다. 처음 박테리아 수 n과 경과 시간 t가 매개변수로 주어질 때, t시간 후 박테리아 수를 return 하라.

## 접근
t시간 후 박테리아 수는 n * 2^t. `pow(a, b)`로 a의 b승을 구할 수 있다.

## 코드
```cpp
#include <cmath>
int solution(int n, int t) {
    return n * pow(2, t);
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `pow` | 2의 t승(시간에 따른 증식 배수)을 계산 |
