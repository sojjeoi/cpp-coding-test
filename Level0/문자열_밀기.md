# 문자열 밀기 (Level 0)

## 문제
문자열 A, B가 주어질 때, A를 오른쪽으로 밀어서(맨 뒤 글자를 맨 앞으로 옮기는 걸 반복) B와 같아지게 만들 수 있는 최소 밀기 횟수를 return 하라. 만들 수 없으면 -1을 return 한다.

## 접근
A가 처음부터 B와 같으면 0. 아니면 A.size()-1번까지 밀어보면서(그 이상 밀면 원래 문자열로 되돌아오므로 더 볼 필요 없음) 매번 B와 같은지 확인한다.
한 번 밀기 = 마지막 글자를 떼서 맨 앞에 붙이기.

## 코드
```cpp
int solution(string A, string B) {
    if (A == B) return 0;
    int answer = 0;
    bool check = false;
    for (int i = 1; i <= A.size() - 1; i++) {
        char c = A[A.size() - 1];
        A = c + A.erase(A.size() - 1, 1);
        answer++;
        if (A == B) { check = true; break; }
    }
    if (check) return answer;
    return -1;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::erase` | 마지막 글자를 제거하고 맨 앞에 붙여 오른쪽으로 한 칸 밀기 |
