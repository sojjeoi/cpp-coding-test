# 옹알이 (1) (Level 0)

## 문제
"aya", "ye", "woo", "ma" 네 가지 발음만 사용해 정확히 발음할 수 있는 문자열 배열 babbling이 주어질 때, 정확하게 발음할 수 있는 단어의 개수를 return 하라. (네 발음 중 일부만 써도 되고, 그 외 다른 글자가 섞여 있으면 안 된다)

## 접근
문자열을 한 글자씩 읽어 temp에 이어 붙이다가, temp가 네 발음 중 하나와 일치하면 temp를 비운다. 문자열 전체를 다 읽었을 때 temp가 비어 있으면(모든 글자가 발음 조각들로 딱 맞게 소비됨) 정확한 발음이다.
(네 발음 중 어느 것도 다른 발음의 접두사가 아니라서, 이렇게 그리디하게 매칭해도 애매함 없이 정확하다.)

## 코드
```cpp
int solution(vector<string> babbling) {
    int answer = 0;
    vector<string> po = {"aya", "ye", "woo", "ma"};
    for (string b : babbling) {
        string temp = "";
        for (char c : b) {
            temp += c;
            for (string p : po) {
                if (temp == p) { temp = ""; break; }
            }
        }
        if (temp.empty()) answer++;
    }
    return answer;
}
```

## 사용 함수
– (문자 단위 그리디 매칭으로 처리)
