# 진료 순서 정하기 (Level 0)

## 문제
정수 배열 emergency가 주어질 때, 값이 클수록 먼저 진료받는다고 할 때 각 사람의 진료 순번을 반환하라.

## 접근
내림차순으로 정렬한 복사본을 만들고, 원본 각 원소의 위치를 find로 찾아 순번(+1)을 매긴다.

## 코드
```cpp
#include <algorithm>
vector<int> solution(vector<int> emergency) {
    vector<int> temp = emergency;
    sort(temp.rbegin(), temp.rend());
    vector<int> answer;
    for (int x : emergency)
        answer.push_back(find(temp.begin(), temp.end(), x) - temp.begin() + 1);
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` (`rbegin`/`rend`) | 역방향 이터레이터로 내림차순 정렬 |
| `find` | 정렬된 복사본에서 원소 위치(=순번) 탐색 |
