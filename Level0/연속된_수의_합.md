# 연속된 수의 합 (Level 0)

## 문제
연속된 수의 개수 num과 목표 합 total이 매개변수로 주어질 때, 연속된 num개의 정수를 더해 total이 되는 수들을 오름차순으로 담은 배열을 return 하라.

## 접근
평균(middle) = total / num을 중심으로 좌우로 num/2씩 뻗은 범위가 답이 된다.
- start = middle - num/2, end = middle + num/2
- num이 홀수면 정확히 `[start, end]`가 num개짜리 정답 범위다.
- num이 짝수면 평균이 정수로 딱 떨어지지 않아(정수 나눗셈으로 버려져서) `[start, end]` 범위가 원래 필요한 것보다 1개 많다. 그래서 `start+1`부터 시작해 개수를 num개로 맞춘다.

## 코드
```cpp
vector<int> solution(int num, int total) {
    vector<int> answer;
    int middle = total / num;
    int start = middle - num / 2;
    int end = middle + num / 2;
    if (num % 2 == 0) {
        for (int i = start + 1; i <= end; i++) answer.push_back(i);
    } else {
        for (int i = start; i <= end; i++) answer.push_back(i);
    }
    return answer;
}
```
