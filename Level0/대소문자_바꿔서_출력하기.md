# 대소문자 바꿔서 출력하기 (Level 0)

## 문제
문자열을 입력받아 대문자는 소문자로, 소문자는 대문자로 바꿔서 화면에 출력하라. (반환값 없음, 표준입출력)

## 접근
toupper/tolower는 반환형이 int이기 때문에 cout에 바로 넘기면 문자가 아니라 숫자로 출력된다.
그래서 `(char)toupper(c)`처럼 char로 캐스팅해서 출력해야 한다.

## 코드
```cpp
#include <iostream>
#include <cctype>
using namespace std;
int main() {
    string str;
    cin >> str;
    for (char c : str) {
        if (islower(c)) cout << (char)toupper(c);
        else if (isupper(c)) cout << (char)tolower(c);
    }
    return 0;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `toupper` / `tolower` | 대소문자 변환 (반환형 int → `(char)` 캐스팅 필요) |
