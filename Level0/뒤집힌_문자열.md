# 뒤집힌 문자열 (Level 0)

## 문제
문자열 my_string이 주어질 때 이를 거꾸로 뒤집어 반환하라.

## 접근
reverse()로 문자열을 뒤집는다.

## 코드
```cpp
#include <algorithm>
string solution(string my_string) {
    reverse(my_string.begin(), my_string.end());
    return my_string;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `reverse` | 컨테이너 내 원소 순서를 뒤집기 |
