# 배열의 유사도 (Level 0)

## 문제
두 문자열 배열 s1, s2가 주어질 때 공통으로 포함된 원소의 개수를 반환하라.

## 접근
s1의 각 원소가 s2에 존재하는지 find로 확인, 있으면 count.

## 코드
```cpp
#include <algorithm>
int solution(vector<string> s1, vector<string> s2) {
    int answer = 0;
    for (string& s : s1)
        if (find(s2.begin(), s2.end(), s) != s2.end()) answer++;
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `find` | 컨테이너 안에서 값 존재 여부 탐색 (없으면 end() 반환) |
