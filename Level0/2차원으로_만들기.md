# 2차원으로 만들기 (Level 0)

## 문제
1차원 배열 num_list와 정수 n이 주어질 때, n개씩 잘라 2차원 배열로 만들어 반환하라.

## 접근
n개 단위로 순회하며 temp 배열에 채운 뒤 answer에 push_back.

## 코드
```cpp
vector<vector<int>> solution(vector<int> num_list, int n) {
    vector<vector<int>> answer;
    for (int i = 0; i < (int)num_list.size(); i += n) {
        vector<int> temp;
        for (int j = i; j < i + n; j++) temp.push_back(num_list[j]);
        answer.push_back(temp);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 for문만 사용, STL 없음 |
