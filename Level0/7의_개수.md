# 7의 개수 (Level 0)

## 문제
행운의 숫자 7을 좋아하는 머쓱이를 위해, 정수 배열 array가 매개변수로 주어질 때 배열의 모든 원소에 7이 총 몇 개 있는지 return 하라.

## 접근
각 원소를 `to_string`으로 문자열로 바꾸고, `count`로 '7' 문자의 개수를 세어 누적한다.

## 코드
```cpp
#include <string>
#include <algorithm>
int solution(vector<int> array) {
    int answer = 0;
    for (int num : array) {
        string s = to_string(num);
        answer += count(s.begin(), s.end(), '7');
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 바꿔 자릿수 단위로 검사 |
| `count` | 문자열 안의 '7' 개수를 셈 |
