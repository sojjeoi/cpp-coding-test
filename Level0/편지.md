# 편지 (Level 0)

## 문제
message 문자열이 주어질 때, 마지막 공백을 제외한 문자 수 × 2(왕복)를 반환하라.

## 접근
뒤에서부터 공백을 제거한 뒤 남은 길이에 2를 곱한다.

## 코드
```cpp
int solution(string message) {
    int len = message.length();
    while (len > 0 && message[len-1] == ' ') len--;
    return len * 2;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| – | 기본 while문만 사용, STL 없음 |
