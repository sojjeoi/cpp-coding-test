# 저주의 숫자 3 (Level 0)

## 문제
숫자 3의 배수이거나 숫자에 3이 들어가는 수는 사용하지 않는다. 1부터 시작해서 이런 "저주받은 수"를 건너뛰며 셀 때, n번째로 도달하는 수를 return 하라.

## 접근
plus는 원래 순번(i)에 더해지는 보정값이다. 후보 num = i + plus가
- 3의 배수이거나 (`num % 3 == 0`)
- 숫자에 3이 포함되면 (`to_string(num).find('3') != string::npos`)

plus를 1 늘리고 다시 검사한다. **plus를 늘린 뒤에도 두 조건을 다시 만족할 수 있으므로, 둘 중 하나도 걸리지 않을 때까지 while로 계속 재검사**해야 한다. 조건 중 하나만 걸렸다고 +1 하고 바로 끝내면 안 된다.

`num`은 while 블록 안에서 매번 새로 선언되는 지역 변수라 블록을 벗어나면 사라진다. 그래서 while을 빠져나온 뒤에는 `num` 대신 `i + plus`로 다시 계산해서 써야 한다.

## 코드
```cpp
#include <string>
using namespace std;

int solution(int n) {
    int plus = 0;
    int answer = 0;
    for (int i = 1; i <= n; i++) {
        while (true) {
            int num = i + plus;
            if (num % 3 == 0 || to_string(num).find('3') != string::npos) plus++;
            else break;
        }
        answer = i + plus;
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 바꿔 자릿수에 '3'이 있는지 검사 |
| `string::find` | 문자열에 특정 문자가 포함되는지 검사 |
