# 외계어 사전 (Level 0)

## 문제
철자 목록 spell의 모든 문자열이 부분 문자열로 포함된 단어가 dic에 하나라도 있으면 1, 없으면 2를 반환하라.

## 접근
dic의 각 단어에 대해 spell의 모든 단어가 부분 문자열로 포함되는지 확인, 하나라도 만족하면 1, 끝까지 없으면 2.

## 코드
```cpp
int solution(vector<string> spell, vector<string> dic) {
    for (string& d : dic) {
        bool ok = true;
        for (string& s : spell) {
            if (d.find(s) == string::npos) { ok = false; break; }
        }
        if (ok) return 1;
    }
    return 2;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::find` | 단어 안에 부분 문자열이 포함되는지 확인 |
