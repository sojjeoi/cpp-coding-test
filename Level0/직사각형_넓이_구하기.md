# 직사각형 넓이 구하기 (Level 0)

## 문제
좌표 평면 위 네 꼭짓점의 좌표가 담긴 2차원 배열 dots가 매개변수로 주어질 때, 네 점을 이용해 만들 수 있는 직사각형의 넓이를 return 하라.

## 접근
dots를 정렬하면 첫 번째 기준(x) 오름차순, 같으면 두 번째 기준(y) 오름차순으로 정렬된다. 정렬 후 `dots[0]`이 가장 작은(왼쪽 아래) 점, `dots[3]`이 가장 큰(오른쪽 위) 점이 되므로, 두 점의 x좌표 차이가 너비, y좌표 차이가 높이가 된다.

## 코드
```cpp
#include <algorithm>
#include <cmath>
int solution(vector<vector<int>> dots) {
    sort(dots.begin(), dots.end());
    int width = abs(dots[0][0] - dots[3][0]);
    int height = abs(dots[0][1] - dots[3][1]);
    return width * height;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 2차원 벡터를 첫 원소 오름차순, 같으면 둘째 원소 오름차순으로 정렬 |
| `abs` | 정렬된 최소/최대 좌표 차이(너비·높이)를 절댓값으로 계산 |
