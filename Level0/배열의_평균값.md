# 배열의 평균값 (Level 0)

## 문제
정수 배열 numbers가 주어질 때 원소들의 평균값을 반환하라.

## 접근
accumulate로 합을 구하고 개수로 나눈다.

## 코드
```cpp
#include <numeric>
double solution(vector<int> numbers) {
    return accumulate(numbers.begin(), numbers.end(), 0.0) / numbers.size();
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `accumulate` | 컨테이너 원소 합산 (초기값 0.0으로 double 연산 유도) |
