# 분수의 덧셈 (Level 0)

## 문제
첫 번째 분수의 분자·분모 numer1, denom1과 두 번째 분수의 분자·분모 numer2, denom2가 주어질 때, 두 분수를 더한 값을 기약분수로 만들어 [분자, 분모] 형태로 반환하라.
예) 1/2 + 3/4 = 5/4 (0.5 + 0.75 = 1.25)

## 접근
통분해서 분자와 분모를 각각 구한 뒤, 둘의 최대공약수로 나눠서 기약분수로 만든다.
- 분자 = numer1 * denom2 + numer2 * denom1
- 분모 = denom1 * denom2
- 예: 1/2 + 3/4 → 분자 10, 분모 8, gcd(10, 8) = 2 → 5/4

## 코드
```cpp
#include <numeric>
vector<int> solution(int numer1, int denom1, int numer2, int denom2) {
    int numer = numer1 * denom2 + numer2 * denom1;
    int denom = denom1 * denom2;
    int g = gcd(numer, denom);
    return {numer / g, denom / g};
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `gcd` | 분자와 분모의 최대공약수를 구해 기약분수로 약분 |
