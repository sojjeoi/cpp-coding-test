# 가장 가까운 수 (Level 0)

## 문제
정수 배열 array와 정수 n이 주어질 때, array 안에서 n과 가장 가까운 수를 반환하라. 가장 가까운 수가 여러 개면 그중 더 작은 수를 반환하라.

## 접근
먼저 array를 오름차순으로 정렬한다. 그러면 절대값 차이가 같은 후보가 여러 개 있어도 더 작은 값이 먼저 나오므로,
"더 작은 diff일 때만" 갱신하는 조건(`<`, `<=`가 아님)으로 순회하면 동률일 때 자동으로 더 작은 수가 유지된다.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> array, int n) {
    sort(array.begin(), array.end());
    int min_diff = abs(n - array[0]);
    int answer = array[0];
    for (int i = 0; i < array.size(); i++) {
        int diff = abs(n - array[i]);
        if (diff < min_diff) {
            min_diff = diff;
            answer = array[i];
        }
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 동률일 때 더 작은 값이 먼저 오도록 오름차순 정렬 |
| `abs` | n과의 차이를 절대값으로 계산 |
