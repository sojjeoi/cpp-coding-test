# 특이한 정렬 (Level 0)

## 문제
정수 배열 numlist와 기준값 n이 매개변수로 주어질 때, n과의 차이(절댓값)가 작은 순서로 정렬하고, 차이가 같으면 더 큰 값이 앞에 오도록 정렬한 배열을 return 하라.
예) [1,2,3,4,5,6], n=4 → 4와의 차이가 작은 순서, 차이가 같으면 큰 값 우선.

## 접근
`sort`에 커스텀 비교자(람다)를 넘긴다. `abs(n-a)`와 `abs(n-b)`가 같으면 더 큰 값이 앞으로(`a > b`), 다르면 차이가 작은 쪽이 앞으로(`abs(n-a) < abs(n-b)`) 오도록 비교한다.

## 코드
```cpp
#include <algorithm>
#include <cmath>
vector<int> solution(vector<int> numlist, int n) {
    sort(numlist.begin(), numlist.end(), [n](int a, int b) {
        if (abs(n - a) == abs(n - b)) return a > b;
        return abs(n - a) < abs(n - b);
    });
    return numlist;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` | 람다 비교자로 n과의 거리 기준 정렬 |
| `abs` | n과의 차이를 절댓값으로 비교 |
