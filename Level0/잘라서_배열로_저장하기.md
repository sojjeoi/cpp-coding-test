# 잘라서 배열로 저장하기 (Level 0)

## 문제
문자열 my_str과 정수 n이 주어질 때, my_str을 n개씩 잘라 문자열 배열로 반환하라.

## 접근
substr(i, n)으로 n글자씩 잘라 배열에 push_back.

## 코드
```cpp
vector<string> solution(string my_str, int n) {
    vector<string> answer;
    for (int i = 0; i < (int)my_str.length(); i += n)
        answer.push_back(my_str.substr(i, n));
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `substr` | 문자열에서 지정한 길이만큼 부분 문자열 추출 |
