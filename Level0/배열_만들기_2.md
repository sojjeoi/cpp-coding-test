# 배열 만들기 2 (Level 0)

## 문제
정수 l, r이 주어질 때, l 이상 r 이하의 정수 중에서 0과 5로만 이루어진 수를 오름차순으로 담은 배열을 return 하라. 그런 수가 없으면 [-1]을 return 한다.

## 접근
l부터 r까지 각 수를 문자열로 바꿔, 0과 5가 아닌 숫자(1,2,3,4,6,7,8,9)가 하나라도 있는지 확인한다. 하나도 없으면 answer에 담는다. 반복문이 끝난 뒤 answer가 비어 있으면 -1을 넣는다.

## 코드
```cpp
vector<int> solution(int l, int r) {
    vector<int> answer;
    string no = "12346789"; // 0, 5를 제외한 숫자
    for (int i = l; i <= r; i++) {
        string s = to_string(i);
        bool check = true;
        for (char c : s) {
            if (no.find(c) != string::npos) { check = false; break; }
        }
        if (check) answer.push_back(i);
    }
    if (answer.empty()) answer.push_back(-1);
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 정수를 문자열로 바꿔 자릿수 단위로 검사 |
| `string::find` | 0, 5가 아닌 숫자가 포함되는지 확인 |
