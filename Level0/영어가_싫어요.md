# 영어가 싫어요 (Level 0)

## 문제
영어로 표기된 숫자(zero, one, two, ...)가 공백 없이 이어붙어 있는 문자열 numbers가 주어질 때, 이를 정수로 변환해 반환하라. 값의 범위가 커서 long long을 사용해야 한다.

## 접근
numbers는 띄어쓰기로 구분돼 있지 않으므로, 문자를 하나씩 temp에 이어붙이면서 map에 등록된 영어 숫자 단어와 일치하는지 확인한다.
일치하면 대응하는 숫자 문자를 answer에 추가하고 temp를 초기화한다. 마지막에 문자열 answer를 stoll로 정수 변환한다.

## 코드
```cpp
#include <map>
long long solution(string numbers) {
    map<string, char> m = {
        {"zero",'0'},{"one",'1'},{"two",'2'},{"three",'3'},{"four",'4'},
        {"five",'5'},{"six",'6'},{"seven",'7'},{"eight",'8'},{"nine",'9'}
    };
    string answer = "";
    string temp = "";
    for (char c : numbers) {
        temp += c;
        if (m.find(temp) != m.end()) {
            answer += m[temp];
            temp = "";
        }
    }
    return stoll(answer);
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `map` | 영어 숫자 단어 → 숫자 문자 매핑 |
| `stoll` | 완성된 숫자 문자열을 long long으로 변환 |
