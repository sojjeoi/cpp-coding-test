# 문자열 계산하기 (Level 0)

## 문제
"3 + 4 - 2"처럼 공백으로 구분된 수식 문자열 my_string이 주어질 때 계산 결과를 반환하라. 연산자는 1개 이상 나올 수 있다.

## 접근
stringstream으로 공백 단위 토큰을 순서대로 뽑는다. 맨 처음엔 숫자 하나만 먼저 읽고,
그 다음부터는 "연산자, 숫자" 쌍을 반복해서 읽으며 +면 더하고 -면 뺀다.

## 코드
```cpp
#include <sstream>
int solution(string my_string) {
    stringstream ss(my_string);
    int answer;
    char op;
    int num;
    ss >> answer;
    while (ss >> op >> num) {
        if (op == '+') answer += num;
        else answer -= num;
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `stringstream` | 공백 기준으로 숫자/연산자 토큰을 순서대로 읽기 |
