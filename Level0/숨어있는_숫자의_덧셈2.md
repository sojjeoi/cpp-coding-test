# 숨어있는 숫자의 덧셈 (2) (Level 0)

## 문제
영어 대소문자와 자연수(여러 자리일 수 있음)가 섞인 문자열 my_string이 주어질 때, my_string에 나타나는 모든 자연수의 합을 return 하라.

## 접근
숫자가 아닌 문자를 전부 공백(" ")으로 바꿔 숫자 토큰들만 공백으로 구분되게 만든 뒤, `stringstream`으로 토큰을 하나씩 읽어 `stoi`로 더한다. `isdigit`으로 문자가 0~9인지 확인한다.

## 코드
```cpp
#include <sstream>
#include <cctype>
using namespace std;

int solution(string my_string) {
    for (int i = 0; i < my_string.size(); i++) {
        if (!isdigit(my_string[i])) my_string.replace(i, 1, " ");
    }
    int answer = 0;
    string s;
    stringstream ss(my_string);
    while (ss >> s) {
        answer += stoi(s);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `isdigit` | 문자가 0~9 숫자인지 확인 |
| `string::replace` | 숫자가 아닌 문자를 공백으로 치환 |
| `stringstream` | 공백으로 구분된 숫자 토큰을 하나씩 읽기 |
| `stoi` | 문자열 토큰을 정수로 변환 |
