# 인덱스 바꾸기 (Level 0)

## 문제
문자열 my_string과 정수 num1, num2가 주어질 때, my_string의 num1번째와 num2번째 문자를 서로 바꾼 문자열을 반환하라.

## 접근
`swap(a, b)`으로 두 인덱스의 문자를 그대로 맞바꾸면 된다.

## 코드
```cpp
#include <algorithm>
string solution(string my_string, int num1, int num2) {
    swap(my_string[num1], my_string[num2]);
    return my_string;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `swap` | 두 인덱스의 문자를 서로 교환 |
