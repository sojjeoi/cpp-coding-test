# 중복된 숫자 개수 (Level 0)

## 문제
정수 배열 array와 정수 n이 주어질 때, array 안에 n이 몇 번 있는지 반환하라.

## 접근
count()로 배열 내 n의 개수를 바로 센다.

## 코드
```cpp
#include <algorithm>
int solution(vector<int> array, int n) {
    return count(array.begin(), array.end(), n);
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `count` | 컨테이너 내 특정 값의 개수 세기 |
