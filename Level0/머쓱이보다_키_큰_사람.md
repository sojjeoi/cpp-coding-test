# 머쓱이보다 키 큰 사람 (Level 0)

## 문제
머쓱이의 키 height와 반 학생들의 키가 담긴 정수 배열 array가 매개변수로 주어질 때, 머쓱이보다 키가 큰 학생 수를 return 하라.

## 접근
array를 순회하며 각 키가 height보다 크면 카운트를 늘린다.

## 코드
```cpp
int solution(vector<int> array, int height) {
    int answer = 0;
    for (int h : array) {
        if (h > height) answer++;
    }
    return answer;
}
```

## 사용 함수
– (반복문만으로 처리)
