# 한번만 등장한 문자 (Level 0)

## 문제
문자열 s가 주어질 때, s에서 딱 한 번만 등장하는 문자들을 사전순으로 정렬한 문자열을 반환하라.

## 접근
s를 순회하면서 각 문자가 s 전체에서 몇 번 등장하는지 count로 센다. 등장 횟수가 1이면 answer에 추가하고,
마지막에 answer를 sort로 정렬한다. count가 1이면 애초에 한 번만 순회 중 만나므로 중복 추가 걱정은 없다.

## 코드
```cpp
#include <algorithm>
string solution(string s) {
    string answer = "";
    for (char c : s) {
        if (count(s.begin(), s.end(), c) == 1) answer += c;
    }
    sort(answer.begin(), answer.end());
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `count` | 문자가 문자열 전체에서 몇 번 등장하는지 세기 |
| `sort` | 한 번만 등장한 문자들을 사전순 정렬 |
