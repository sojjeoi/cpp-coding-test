# 푸드파이트 대회 (Level 1)

## 문제
음식의 수를 나타내는 정수 배열 food가 주어진다(food[0]은 사용하지 않음). 대회 진행자를 기준으로 좌우가 대칭이 되도록 각 음식을 나눠 먹어야 할 때, 만들 수 있는 최댓값의 대칭 문자열을 return 하라. (각 음식 번호를 그 음식을 나눠 먹을 수 있는 개수만큼 반복해서 왼쪽에 오름차순으로 배치하고, 가운데 '0', 오른쪽은 왼쪽을 뒤집은 것)

## 접근
음식마다 몇 인분씩 좌우로 나눠줄 수 있는지는 `food[i] / 2`로 구한다. 홀수 개면 정수 나눗셈이 자동으로 1개를 버려주므로 따로 처리할 필요가 없다. 왼쪽 문자열을 완성한 뒤 그대로 뒤집어 오른쪽에 붙이고, 가운데에 진행자 표시 "0"을 넣는다.

## 코드
```cpp
#include <algorithm>
using namespace std;

string solution(vector<int> food) {
    string left = "";
    for (int i = 1; i < food.size(); i++) {
        for (int j = 0; j < food[i] / 2; j++) left += to_string(i);
    }
    string right = left;
    reverse(right.begin(), right.end());
    return left + "0" + right;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `to_string` | 음식 번호를 문자로 이어붙이기 위해 변환 |
| `reverse` | 왼쪽 문자열을 뒤집어 대칭인 오른쪽 문자열 생성 |
