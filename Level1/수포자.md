# 모의고사 (수포자) (Level 1)

## 문제
수포자 1, 2, 3은 각자 정해진 패턴을 반복해서 찍는다. 실제 정답 배열 answers가 주어질 때, 가장 많은 문제를 맞힌 사람의 번호를 오름차순 배열로 return 하라. (동점이면 모두 return)

## 접근
세 명의 반복 패턴을 각각 배열로 저장해두고, 문제 번호 i에 대해 `패턴[i % 패턴.size()]`로 그 사람이 그 문제에 찍은 답을 구한다. 정답과 비교해 맞으면 그 사람의 점수를 올린다. 최고점을 구한 뒤, 그 점수와 같은 사람들의 번호를 모아 return한다.

## 코드
```cpp
#include <algorithm>
using namespace std;

vector<int> solution(vector<int> answers) {
    vector<int> answer;
    vector<int> one = {1, 2, 3, 4, 5};
    vector<int> two = {2, 1, 2, 3, 2, 4, 2, 5};
    vector<int> three = {3, 3, 1, 1, 2, 2, 4, 4, 5, 5};
    vector<int> score = {0, 0, 0};

    for (int i = 0; i < answers.size(); i++) {
        if (answers[i] == one[i % one.size()]) score[0]++;
        if (answers[i] == two[i % two.size()]) score[1]++;
        if (answers[i] == three[i % three.size()]) score[2]++;
    }

    int maxScore = *max_element(score.begin(), score.end());
    for (int i = 0; i < 3; i++) {
        if (score[i] == maxScore) answer.push_back(i + 1);
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `max_element` | 세 사람의 점수 중 최고점 찾기 |
