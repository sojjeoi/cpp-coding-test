# 콜라즈 추측 (Level 1)

## 문제
임의의 자연수 num이 1이 될 때까지 짝수면 2로 나누고 홀수면 3배 후 1을 더하는 과정을 반복한다. 이 과정을 500번 이내에 1로 만들 수 있으면 그 횟수를, 500번을 시도해도 1이 되지 않으면 -1을 return 하라. (1 ≤ num ≤ 8,000,000)

## 접근
num을 int로 두면 `num*3+1`을 반복하는 과정에서 값이 int 범위를 넘어설 수 있으므로, 계산에 사용하는 변수는 long long으로 선언한다.

## 코드
```cpp
int solution(int num) {
    long long n = num;
    int count = 0;
    while (n != 1) {
        if (count == 500) return -1;
        n = (n % 2 == 0) ? n / 2 : n * 3 + 1;
        count++;
    }
    return count;
}
```

## 사용 함수
– (long long으로 오버플로 방지, 반복 횟수 제한으로 처리)
