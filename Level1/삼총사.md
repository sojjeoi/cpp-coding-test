# 삼총사 (Level 1)

## 문제
정수 배열 number에서 서로 다른 세 인덱스의 수를 뽑아 더했을 때 합이 0이 되는 조합의 개수를 return 하라.

## 접근
세 개의 중첩 반복문으로 가능한 모든 조합(i<j<k)을 만들어 합을 확인한다.

## 코드
```cpp
int solution(vector<int> number) {
    int answer = 0;
    int n = number.size();
    for (int i = 0; i < n - 2; i++) {
        for (int j = i + 1; j < n - 1; j++) {
            for (int k = j + 1; k < n; k++) {
                if (number[i] + number[j] + number[k] == 0) answer++;
            }
        }
    }
    return answer;
}
```

## 사용 함수
– (3중 반복문으로 완전탐색)
