# 폰켓몬 (Level 1)

## 문제
포켓몬 종류 번호가 담긴 정수 배열 nums에서 nums.size()/2 마리를 가져갈 수 있을 때, 가져갈 수 있는 포켓몬의 최대 "종류" 수를 return 하라.

## 접근
가져갈 수 있는 마리 수(nums.size()/2)와 실제 존재하는 종류 수(중복 제거한 개수) 중 더 작은 쪽이 답이다. 프로그래머스에서는 이 문제가 "해시" 챕터에 속해 `unordered_set`으로 중복을 세는 게 정석이지만, `sort`+`unique`로 중복을 제거해도 결과는 같다.

## 코드
```cpp
// 방법 1: sort + unique로 중복 제거
#include <algorithm>
using namespace std;

int solution(vector<int> nums) {
    int take = nums.size() / 2;
    sort(nums.begin(), nums.end());
    nums.erase(unique(nums.begin(), nums.end()), nums.end());
    return min(take, (int)nums.size());
}
```

```cpp
// 방법 2: 해시(unordered_set)로 중복 제거
#include <unordered_set>
using namespace std;

int solution(vector<int> nums) {
    unordered_set<int> s(nums.begin(), nums.end());
    return min((int)nums.size() / 2, (int)s.size());
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `sort` + `unique` | 정렬 후 중복 제거로 종류 수 계산 |
| `unordered_set` | 해시로 중복 제거해 종류 수 계산 (같은 목적의 다른 방법) |
