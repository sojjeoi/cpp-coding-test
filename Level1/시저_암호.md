# 시저 암호 (Level 1)

## 문제
문자열 s와 정수 n이 주어질 때, 알파벳은 각각 n칸씩 밀어서(순환) 암호화하고 공백은 그대로 유지한 문자열을 return 하라. 대소문자 구분을 유지한다.

## 접근
알파벳에서 문자의 인덱스를 찾고 n을 더한 뒤, 26으로 나눈 나머지(`%`)를 이용해 범위를 넘어가면 자연스럽게 처음으로 순환하게 만든다. 공백은 그대로 두고, 대문자/소문자를 각각 다른 알파벳 문자열로 처리한다.

## 코드
```cpp
#include <cctype>
using namespace std;

string solution(string s, int n) {
    string answer = "";
    string lower = "abcdefghijklmnopqrstuvwxyz";
    string upper = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    for (char c : s) {
        if (c == ' ') answer += ' ';
        else if (islower(c)) answer += lower[(lower.find(c) + n) % lower.size()];
        else answer += upper[(upper.find(c) + n) % upper.size()];
    }
    return answer;
}
```

## 사용 함수
| 함수 | 용도 |
|---|---|
| `string::find` | 문자의 알파벳 내 인덱스 찾기 |
| `islower` | 소문자/대문자 알파벳 구분 |
