# [1차] 비밀지도 (Level 1)

## 문제
지도의 크기 n과, 각 지도를 나타내는 정수 배열 arr1, arr2가 주어진다. 각 배열의 원소를 이진수로 표현했을 때 1이면 벽, 0이면 공백을 뜻한다. 두 지도를 겹쳤을 때(하나라도 벽이면 벽) 나타나는 실제 지도를 벽은 '#', 공백은 ' '으로 표현한 문자열 배열로 return 하라.

## 접근
int형은 이미 컴퓨터 내부에서 이진수로 저장되어 있으므로, 굳이 별도로 이진수 문자열로 변환할 필요 없이 비트 연산으로 바로 처리한다.
- 두 지도를 겹치는 것은 OR 연산: `arr1[i] | arr2[i]`
- 특정 비트(j번째)가 1인지 확인하려면 `sum & (1 << j)`가 0이 아닌지 본다.
- n비트를 표현하므로 비트 위치는 n-1부터 0까지 높은 자리부터 확인해야 문자열이 올바른 순서로 만들어진다.

(반대로, "이진수 문자열" → 정수로 바꾸려면 `stoi(문자열, nullptr, 2)`를 쓰면 된다.)

## 코드
```cpp
vector<string> solution(int n, vector<int> arr1, vector<int> arr2) {
    vector<string> answer;
    for (int i = 0; i < n; i++) {
        int sum = arr1[i] | arr2[i];
        string result = "";
        for (int j = n - 1; j >= 0; j--) {
            result += (sum & (1 << j)) ? '#' : ' ';
        }
        answer.push_back(result);
    }
    return answer;
}
```

## 사용 함수
– (비트 연산 `|`, `&`, `<<`로 처리)
