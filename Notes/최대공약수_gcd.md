# 최대공약수 / 최소공배수 (gcd, lcm)

## 개념
- 최대공약수(GCD): 두 수를 모두 나누어떨어지게 하는 가장 큰 수
- 최소공배수(LCM): 두 수의 공통 배수 중 가장 작은 수
- 관계: `gcd(a, b) * lcm(a, b) == a * b`

## 사용법
`<numeric>` 헤더의 `gcd()`, `lcm()`을 쓰면 직접 유클리드 호제법을 짤 필요가 없다. (C++17 이상)

```cpp
#include <numeric>

int g = gcd(12, 18);   // 6
int l = lcm(12, 18);   // 36
```
